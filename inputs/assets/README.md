# Assets

Binary objects that outputs embed, by kind and purpose:

```text
assets/
├── images/
│   ├── avatars/       portraits
│   ├── signatures/    handwritten signatures
│   ├── logos/
│   ├── icons/
│   └── backgrounds/
├── documents/         diplomas/, transcripts/, certificates/, references/,
│                      publications/, permits/
└── videos/
```

Folders are created when their first file arrives. Binary assets are stored
with Git LFS.
