# Library

Material that is consulted while writing and designing, but never rendered:

```text
library/
├── inspiration/   external designs to borrow form from, by output type:
│                  cvl/, flyers/, web/, videos/, presentations/, portfolios/
├── studies/       own studies of what works and why
├── research/      market and role research; events/ holds event material
└── norms/         official, non-negotiable rules (formats, regulations)
```

A folder is created when its first file arrives. In this public repository
the library holds only the author's own or freely licensed material, with its
licence recorded in `REUSE.toml`; third-party material stays in a private
workspace.
